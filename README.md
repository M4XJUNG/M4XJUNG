## 🚧 Current Project

### [financial-research](https://github.com/M4XJUNG/financial-research)

I'm currently building an evolving financial-data research platform that connects:

<pre>
Financial Data
      ↓
Collection / Validation / Storage
      ↓
Statistics / Time Series / ML
      ↓
Quantitative Research
      ↓
Signal & Strategy Research
      ↓
Backtesting / Portfolio Analysis
      ↓
Research System
</pre>

**Current Phase: Phase 1 — Financial Database Infrastructure**

The long-term goal of this project is to understand and implement the full research workflow:

- collecting, cleaning, and structuring financial data
- building reproducible financial datasets
- formulating quantitative investment hypotheses
- applying statistics, time-series models, and machine learning
- validating models with proper temporal evaluation
- developing and backtesting systematic strategies
- connecting research results to usable research systems
